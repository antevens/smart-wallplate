# EU boards v0.2 – PCBWay order packs

Generated by `make pcb` (`pcb/eu/tools/build.sh`), one folder per board. Do the review checklist
below before ordering. Spacing values are design targets, not a compliance claim, and the EU stack
depth is still to be tried in a real box (D-36).

| File (in each board's folder) | Use |
| --- | --- |
| `<board>_v0.2_gerbers.zip` | Upload as the PCB file: RS-274X Gerbers, Excellon drills in mm (PTH and NPTH separate), drill maps |
| `<board>_v0.2_bom.csv` | Assembly BOM with MPNs (the mains board's S1 has quantity 0: do not fit) |
| `<board>_v0.2_centroid.csv` | Centroid, both sides, origin = board centre (S1 and the mounting holes left out) |
| `<board>_v0.2_assembly_front.pdf`, `_assembly_back.pdf` | Assembly drawings (back mirrored) |
| `<board>_v0.2_schematic.pdf` | Schematic |
| `erc.rpt`, `drc.rpt` | ERC and DRC reports of this build (all severities, schematic parity on) |
| `gerbers/` | The unzipped Gerber and drill files |

## Mains board (`eu_mains_board/`)

- Round, 57.9 mm across, notched for the box's four screw domes; 2 layers, FR-4, 1.6 mm.
- Copper weight: 2 oz recommended for the load paths (L / N pours carry the lights' current);
  confirm in the thermal review.
- **The outline has a routed relief slot under the PSU.** It is part of Edge.Cuts, not a drill: add
  "routed isolation slot in outline, do not omit" to the order remarks.
- Three Ø2.2 holes for the cap's long bosses (M2), no copper within 1.0 mm.
- Front (F): F1, RV1, J3 (SMD). Back (B): J1, J2 (WAGO 2604-3102), PS1 (Traco TMPS 03-105), THT.
- S1 (Marquardt 1802.2504) is **not fitted** by PCBWay: it snaps into the cap's cup first and is then
  soldered by hand.

## 5 V board (`eu_5v_board/`)

- D-shaped, 57.9 × 27.9 mm, notched round the domes and the mains board's boss; 2 layers, FR-4, 1.6 mm,
  1 oz.
- Front (F): C1, P1 (GND) and P2 (+5V) Harwin P70-2200045 SMT spring pins. Back (B): J1, Samtec
  SSW-102-01-L-S socket (THT) onto the mains board's TSM header.

## Review checklist (before ordering)

- [ ] Isolation targets on the mains board (L–N and L–L(switched) ≥ 3.5 mm, mains to the 5 V island
      ≥ 8.0 mm plus the slot) reviewed against IEC 60664-1 / 62368-1.
- [ ] Thermal review of the load paths; choose the copper weight.
- [ ] F1 T1A (Traco's recommended input fuse) against the branch circuit's prospective fault current
      (UMT 250 breaking capacity).
- [ ] WAGO 2604-3102 pin rows checked on a part (from WAGO's 3D model).
- [ ] Header / socket stack: TSM post 5.84 mm into the SSW socket (body 8.51 mm), 13.8 mm between the
      boards; 3.08 mm engagement as designed.
- [ ] Spring pin working height on a printed cap (6.4–7.2 mm, designed 6.8 ± 0.3).
- [ ] EU stack depth tried in a real 47 mm box (−43.2 mm deepest part).
- [ ] Approvals of S1, J1, J2, PS1, F1 and RV1 adequate for the installation.
